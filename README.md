# KOTARO ACADEMY

PROMPT MAESTRO

Desarrolla una plataforma SaaS premium de educación médica llamada "Kotaro Academy" (nombre temporal), diseñada para convertirse en la plataforma más completa de preparación para Residentado Médico y formación durante toda la residencia en Latinoamérica.

No quiero una aplicación simple.

Quiero una plataforma de nivel profesional comparable o superior a Amboss, Osmosis, AMBOSS Academy, AMIR, CTO, UWorld, Boards & Beyond, QxMedic y Villamedic, pero con una experiencia de usuario moderna, minimalista, elegante, inmersiva y enfocada en el aprendizaje inteligente.

El diseño debe transmitir:

 Exclusividad

 Premium

 Tecnología

 Medicina

 Tranquilidad

 Confianza

 Alto rendimiento académico

Inspirarse en Apple, Linear, Notion, Stripe, Raycast, Framer, Headspace y Duolingo para la experiencia de usuario.

La aplicación debe estar preparada para crecer durante muchos años.

Debe tener arquitectura modular.

Cada módulo debe ser independiente.

Debe existir separación entre Frontend, Backend, Base de Datos, API, IA y Gestión Académica.

Objetivo Final

Diseña una aplicación que no sea solo un "curso de pediatría", sino un ecosistema inteligente de formación médica, capaz de acompañar al estudiante desde los primeros años de Medicina hasta convertirse en especialista. Cada decisión de diseño, funcionalidad y experiencia de usuario debe responder a tres principios:

Excelencia académica respaldada por evidencia científica.

Aprendizaje activo y personalizado mediante IA, casos clínicos y evaluación continua.

Escalabilidad, permitiendo que la misma plataforma incorpore en el futuro Medicina Interna, Cirugía, Ginecología y Obstetricia, Emergencias, Medicina Familiar y cualquier otra especialidad, manteniendo una experiencia uniforme y una identidad premium.
